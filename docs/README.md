# 5% for Humanity: Winter Appeal

A static website asking people to give **5% of their salary** this winter so families in Gaza, Lebanon, Iran, DR Congo, Sudan, Syria, Yemen and Afghanistan can get warm clothes, food and shelter.

- **Salary calculator** shows 5% (adjustable) per month, per day, for the winter and per year, with a suggested split and a "1,000 people" multiplier.
- **Crisis cards** link to ReliefWeb (UN OCHA) for the latest verified reports.
- **Charity directory** lists 37 on-the-ground organisations, both local and international. You can filter by place and need, or search by name. Every link goes to the charity's official site, so this site never handles money.
- **Winter Pledge** gives you share links (WhatsApp, X, Facebook, copy) and a monthly payday reminder (.ics). Nothing leaves your device.

Plain HTML, CSS and JS with no build step. Open `index.html` in a browser, or host it with GitHub Pages: go to **Settings → Pages → Deploy from a branch → `main` / `/docs`**.

To add or edit charities, change the `CHARITIES` array in `app.js`.
